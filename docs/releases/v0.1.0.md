# EnglishAsk v0.1.0 (Preview)

First downloadable preview for macOS on Apple Silicon (ARM64).

## Requirements

- Apple Silicon Mac (M-series), macOS 12 or later as declared by the app bundle.
- An API key from a supported provider for AI features. Keys are not included.
- Intel Macs, Windows and Linux packages are not included in this release.

## Downloads

- `EnglishAsk-0.1.0-mac-arm64.dmg`: open the disk image and drag EnglishAsk to Applications.
- `EnglishAsk-0.1.0-mac-arm64.zip`: alternative app bundle archive.
- `SHA256SUMS.txt`: checksums for both downloads.

## Important limitations

This preview is ad-hoc signed, not Developer ID signed or Apple notarized. macOS Gatekeeper may block the downloaded app. It is intended for testing, not a notarized production distribution. Do not disable system-wide security protections.

Configure your own provider credentials in Settings. This build disables telemetry. Automatic app updates are not included; install subsequent releases manually.

## Included

- AI-assisted English questions and follow-up conversations.
- Local Markdown study notes and note generation from answers.
- Provider/model settings and pronunciation playback.
- Anki Basic-card generation and text export.

## Verification

1072 source tests passed; 42 opt-in tests were skipped. Frontend TypeScript and production compilation passed. The packaged app loaded its renderer and passed Settings/Notes-list IPC checks using an isolated temporary profile. Archive exclusions, local secret-value scanning, ad-hoc signature verification and DMG checksums passed.

Live provider calls, installation on another Mac and every supported macOS version were not tested.

## Build from source

On an Apple Silicon Mac, run `npm ci` followed by `npm run package:mac`. Outputs are written to `release/`. The release script does not publish automatically.
